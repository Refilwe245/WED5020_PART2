# Project Overview

HoneyLux is a small luxury home décor and lifestyle business offering affordable and elegant products for homes, apartments, and student residences.

The website provides a professional online presence where customers can learn more about HoneyLux, explore its products, submit product enquiries, and find contact information.

The website consists of five main pages:

- Home
- About Us
- Products
- Enquiries
- Contact

The website is designed to provide customers with a simple, friendly, attractive, and easy-to-navigate experience.

---

# Website Goals and Objectives

The main goals and objectives of the HoneyLux website are:

- Provide affordable luxury home décor products for customers.
- Help customers discover unique and hidden décor gems.
- Create a simple, friendly, and easy-to-use website.
- Help customers make their homes feel stylish, elegant, and expensive without spending too much.
- Provide clear and useful information about each product, including descriptions and prices.
- Create an attractive website that reflects the elegant HoneyLux brand.
- Provide customers with an easy way to make product enquiries.
- Provide clear contact information for customers.

# Responsive Design

The HoneyLux website uses responsive CSS to allow the website to adjust to different screen sizes.

The website is designed for:

- Desktop
- Tablet
- Mobile

Media queries are used to change the layout at different screen sizes.

---

# Breakpoints

The website uses CSS media queries to create different layouts for different screen sizes.

### Desktop

The desktop layout uses wider content areas and multi-column layouts where appropriate.

### Tablet

The layout is adjusted to fit medium-sized screens while maintaining readable content and spacing.

### Mobile

The layout changes to a single-column structure where required.

Navigation, text sizes, images, forms, and content spacing are adjusted for smaller screens.

---

# Relative Units

Relative units are used to improve responsiveness.

Examples include:

- `rem`
- `em`
- `%`

These units help elements adjust more effectively to different screen sizes.

---

# Responsive Images

Images are styled so that they can resize according to the screen size.

The HoneyLux website also uses responsive image attributes such as:

- `srcset`
- `sizes`

where appropriate.

The images are prevented from overflowing their containers on smaller screens.
